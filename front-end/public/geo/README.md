# Comunidad de Madrid · cartografía INE 2025

Seccionado cedido por el Instituto Nacional de Estadística.

Source: https://www.ine.es/servergis/rest/services/Hosted/Censo_2025___Número_de_personas/FeatureServer

4518 census sections across 179 municipalities. WGS84, simplified at approximately 5 m, five decimal places. Administrative display/navigation only; not cadastral precision. Boundary dissolved from municipal outlines. Internal sliver holes from simplification are removed.

Rebuild: npm run geo:refresh (internet required). Environmental metrics are supplied separately by the API; no measured noise or air-quality data are contained in these files.
