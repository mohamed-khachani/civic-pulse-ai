# Project presentation

The user wants the Atlas presentation to stay current as this project changes. When work changes datasets, ingestion counts, scraping totals, architecture, or verified implementation status, update the existing presentation's facts and relevant slides as part of that work.

Follow `presentation/AGENTS.md` and the Presentations skill. Use the existing deck, facts manifest, and generator rather than starting another deck. Verify the numbers from local reports or the database, keep available datasets distinct from integrated datasets, and preserve the short Spanish pitch. Changes unrelated to the presentation's content do not require rebuilding it.

Never put API keys, database passwords, or personal addresses in the presentation or its sources.
